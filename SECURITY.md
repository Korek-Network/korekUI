# Security policy

KOREK Miner UI is unaudited Planck testnet software. Report vulnerabilities privately through GitHub's security advisory feature when available; do not publish working exploits before maintainers can investigate.

The application never needs a wallet password, recovery phrase, or private key. It accepts only a node miner endpoint and rewards inner hash. If any person or application asks for your 24-word phrase to mine, stop and do not provide it.

Do not expose the current unauthenticated miner-protocol port to the public internet.
